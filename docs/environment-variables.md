- `LOOPDESK_SESSION_SECRET` is canonical. `MEGASKA_CUSTOM_SESSION_SECRET` is a temporary deprecated alias; a value-free warning is emitted when only the alias is present. `SESSION_SECRET` remains a second compatibility input pending migration.
- `SHOPIFY_API_SECRET_KEY`, `TOKEN_ENCRYPTION_KEY`, and `INTERNAL_DIAGNOSTIC_SECRET` are compatibility names requiring a later controlled removal.
- Merchant variables marked **Migrate** are retained in deployment inventory for Stage 1 only; runtime storefront paths must not select them.

## Removal gates

No legacy variable is approved for Production deletion in Stage 1. Preview deletion is safe only after the consumer list for that row is empty and two-shop UAT passes. See the audit report.
